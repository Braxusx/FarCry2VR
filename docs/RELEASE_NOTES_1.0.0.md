**Far Cry 2 VR 1.0.0** (mod build v229). Native stereo VR for Far Cry 2 with motion controls, by Braxus.

**Download `FarCry2VR-1.0.0.zip`:**
- `FarCry2VR-Launcher_1.0.0.exe` installs the mod into your Steam or GOG game folder (one-click install / uninstall, settings, controls guide).
- `manual_install/` holds the same files for copying into the game's `bin` folder by hand.

**Highlights:**
- Native stereo rendering through the engine itself (per-eye off-axis projection, shared culling and sun shadows), OpenXR output.
- Head tracking; Quest controllers drive the game's own gamepad input.
- Weapons in your hands with per-weapon grips, body holsters, aiming down sights and scopes, physical machete swings, thrown grenades with an arc preview, map/GPS in the hand, monocular tagging, mounted guns.
- Optional: VR climbing, NPC grabbing, flashlight, removing the brown filter and rim lighting, bouncing-NPC fix.
- DLSS/DLAA on NVIDIA RTX GPUs, HUD and menus on floating panels, smooth or snap turning.
- Steam and GOG supported by the same DLL.

**Requirements:** Windows 10/11, Far Cry 2 (Steam or GOG) **set to DirectX 10** (DirectX 9 mode is not supported; choose the DirectX 10 version when launching from Steam, or set `Platform="d3d10a"` in `Documents\My Games\Far Cry 2\GamerProfile.xml`), an OpenXR runtime (e.g. Virtual Desktop VDXR, SteamVR, Quest Link). DLSS needs an NVIDIA RTX GPU.

Includes the NVIDIA DLSS runtime, redistributed as part of this mod (not in the source tree). This product uses NVIDIA DLSS technology. Unofficial fan mod, not affiliated with Ubisoft.
